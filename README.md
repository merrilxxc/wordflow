# WordFlow

Личный тренажёр английских слов (PWA): курс A1–B2 с переводами на русский и украинский, интервальное повторение, 5 видов упражнений, тренировка блоков, уроки «Предложения» с разбором, тексты для чтения, статистика и синхронизация через Supabase.

Открыть: https://merrilxxc.github.io/wordflow/

Подробная инструкция — в файле [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).
