# Остров прогресса — исходники

`world3d.js` в корне проекта — **собранный** файл: three.js r161 плюс всё из этой папки,
упаковано в один скрипт. Руками его не правят.

## Что где
| Файл | Зачем |
|---|---|
| `engine.js` | движок: рельеф, вода, растительность, награды, состояние, камера, анимация |
| `builders.js` | 48 объектов-наград, нарисованных кодом |
| `art.js` | таблица наград, времена года |
| `noise.js` | шум и хэш для процедурной генерации |
| `entry.js` | точка входа: кладёт всё в `window.WF3D` |
| `preview.html` | страница проверки: ползунки, качество, сезоны, счётчик FPS |

Связь с приложением — в `world.js` (корень проекта), он обычный скрипт и правится без сборки.

## Пересборка
Нужен Node. Из папки проекта:

```
npm init -y
npm i three@0.161.0 esbuild
node -e "require('esbuild').build({entryPoints:['src/world/entry.js'],bundle:true,minify:true,format:'iife',target:['es2019'],outfile:'world3d.js',alias:{'three/addons':'node_modules/three/examples/jsm'}})"
```

После пересборки поднять номер версии в `sw.js`, иначе браузеры отдадут старый файл из кэша.

## Проверка
Открыть `src/world/preview.html` (с сайта — `.../wordflow/src/world/preview.html`).
Страница работает без приложения: ползунки размера, здоровья и числа модулей,
переключатели качества и времён года, счётчик кадров. Это самый быстрый способ
померить FPS на телефоне.
